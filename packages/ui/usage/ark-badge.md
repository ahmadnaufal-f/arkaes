Text-only label. Put the text in the default slot.

```html
<ark-badge variant="eyebrow">Case Study</ark-badge>
<ark-badge variant="soft">New</ark-badge>
<ark-badge variant="soft" size="sm">Beta</ark-badge>
```

`variant="eyebrow"` is the mono, rule-prefixed section kicker; `variant="soft"`
is a filled pill. Sizes: `sm | md | lg`.
