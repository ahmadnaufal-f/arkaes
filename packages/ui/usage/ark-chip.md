Small pill for tags, filters, and tech labels. The label goes in the default
slot. Set `href` to render it as a link.

```html
<ark-chip variant="default">TypeScript</ark-chip>
<ark-chip variant="primary">Design Systems</ark-chip>
<ark-chip variant="accent" href="/tags/lit">Lit</ark-chip>
```

Variants: `default | primary | emerging | accent | learning`. Sizes: `sm | md`.
